# VRM Viewer with VRMA Animation

[English](README.md) | [日本語](README-jp.md)

Three.jsとthree-vrmライブラリを使用して構築された、VRMA（VRMアニメーション）サポート付きのWebベースVRM（Virtual Reality Model）ビューアーです。

## 🎮 ライブデモ

**[デモを試す →](https://tk256ailab.github.io/vrm-viewer/)**

## 特徴

- 📱 **レスポンシブデザイン**: デスクトップとモバイルデバイスで動作
- 🎭 **VRMモデルサポート**: VRM 1.0モデルの読み込みと表示
- 🎬 **VRMAアニメーション**: カスタムVRMAアニメーションファイルの再生
- 📂 **ドラッグ&ドロップ**: 自分の`.vrm`/`.vrma`ファイルをページにドロップ、またはファイル選択ボタンから読み込み可能
- 🎮 **インタラクティブコントロール**: アニメーションの再生、一時停止、停止（クリップ切り替え時は滑らかにクロスフェード）
- 🦴 **ポーズ編集**: 指を含む全ヒューマノイドボーンをスライダーで回転。3Dビュー上のボーンハンドルをクリックしてギズモで直接ドラッグ操作も可能
- 😊 **表情コントロール**: モデルが定義する全表情（感情プリセット・口形素・まばたき・カスタム表情）をウェイトスライダーで操作
- 👀 **視線コントロール**: Yaw/Pitchスライダーで目線を指定、またはマウスカーソルを目で追従
- 🎛️ **折りたたみUI**: タブ式コントロールパネル（Animation / Pose / Face）、☰ボタンでパネル全体の表示/非表示を切り替え
- ⚡ **高速パフォーマンス**: 最適化されたレンダリングとアニメーション

1. **このリポジトリをGitHubにフォークまたはアップロード**
2. **GitHub Pagesを有効化**：
   - リポジトリのSettingsに移動
   - 「Pages」セクションまでスクロール
   - 「Source」で「Deploy from a branch」を選択
   - ブランチを「main」、フォルダを「/ (root)」に設定
   - 「Save」をクリック
3. **デモにアクセス** `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

### 方法2: ローカル開発

1. **このリポジトリをクローンまたはダウンロード**
2. **ローカルWebサーバーを起動**（ファイル読み込みに必要）：
   ```bash
   # Pythonを使用
   python -m http.server 8000
   
   # Node.jsを使用
   npx serve .
   
   # PHPを使用
   php -S localhost:8000
   ```
3. **ブラウザを開き** `http://localhost:8000` にアクセス
4. **VRMモデルを読み込み**（ページ読み込み時に自動実行）
5. **VRMAボタンでアニメーションを選択**
6. **再生、一時停止、停止ボタンで再生をコントロール**

## 使用方法

### VRMモデルの読み込み

ビューアーは起動時に同梱の`sample.vrm`を自動的に読み込みます。独自のモデルを使用するには：

- ページ上に`.vrm`ファイルを**ドラッグ&ドロップ**するか、
- **「Open .vrm / .vrma…」**ボタンから`.vrm`ファイルを選択

新しいモデルは即座に現在のモデルと入れ替わります。それまでに読み込んだVRMAボタンはそのまま使用可能で、クリックすれば新しいモデルに対してクリップが再生成されます。

### VRMAアニメーションの再生

1. VRMモデルの読み込みが完全に完了するまで待機
2. VRMAアニメーションボタンのいずれかをクリックしてアニメーションを選択（Angry、Blush、Clapping、Goodbye、Jump、LookAround、Relax、Sad、Sleepy、Surprised、Thinking）。独自の`.vrma`ファイルもドラッグ&ドロップまたはファイル選択で新しいボタンとして追加できます
3. 再生コントロールを使用してアニメーションを管理。再生中に別のクリップへ切り替えるとデフォルトポーズに戻らず滑らかにクロスフェードします

### ポーズ編集（Poseタブ）

**Pose**タブに切り替えると、モデルのポーズを手作業で編集できます：

- 全ヒューマノイドボーンにX/Y/Z回転スライダー（度数指定）。指などの詳細ボーンは折りたたみセクション内にあります
- **3D Bone Handles**が有効なとき、モデル上の球をクリックしてボーンを選択し、ビューポート内の回転ギズモを直接ドラッグできます。スライダーとギズモは双方向に同期します
- **Reset Pose**で全ボーンをレストポーズに戻します
- アニメーション再生中にPoseタブを開くと、その瞬間のポーズが凍結されて編集を続けられます。後でPlayを押すとスケルトンはアニメーションに戻ります（編集はブレンドされません）

### 表情・視線編集（Faceタブ）

**Face**タブに切り替えると、モデルの顔を操作できます：

- 表情スライダー（ウェイト0〜1）は読み込んだモデルの定義から自動生成されます: 感情プリセット、口形素（visemes）、まばたき、カスタム表情
- **Look At**のYaw/Pitchスライダーで目線を手動指定、または**Follow Mouse**を有効にするとカーソルを目で追従します（アニメーション再生中も動作）
- **Reset Face**で全表情をゼロにし、視線を中央に戻します
- Poseタブと同様、再生中に開くとその瞬間の表情が凍結されて編集できます

### カメラ操作

- **回転**: 左クリックしながらドラッグでモデルを中心にカメラを回転
- **並行移動**: 右クリックしながらドラッグでカメラを水平/垂直方向に移動
- **ズーム**: マウスホイールでズームイン/アウト

### コントロール

- **☰トグル**: コントロールパネル全体の表示/非表示（非表示中もアニメーション再生・ポーズ編集・視線追従は継続します）
- **Animation / Pose / Faceタブ**: 再生・ボーン編集・表情操作の切り替え
- **VRMAアニメーションボタン**: 異なるアニメーションの選択と読み込み
- **再生**: アニメーション再生の開始または再開
- **一時停止**: 現在のアニメーションの一時停止/再開
- **停止**: アニメーションを停止し、ポーズ・表情・視線をデフォルトにリセット

## 技術詳細

### 依存関係

- [Three.js](https://threejs.org/) - 3Dグラフィックスライブラリ
- [@pixiv/three-vrm](https://github.com/pixiv/three-vrm) - VRMモデルサポート
- [@pixiv/three-vrm-animation](https://github.com/pixiv/three-vrm-animation) - VRMAアニメーションサポート

### アニメーション仕様

- **フォーマット**: glTFバイナリ形式のVRMA（VRMアニメーション）ファイル
- **ヒューマノイドボーン**: VRM 1.0ヒューマノイド仕様と互換
- **フレームレート**: 線形補間による60 FPS
- **継続時間**: 可変（含まれるアニメーションは4-12秒）

### ブラウザ互換性

- ✅ Chrome 80+
- ✅ Firefox 75+
- ✅ Safari 14+
- ✅ Edge 80+

## カスタマイズ

### 新しいアニメーションの追加

1. VRMAアニメーションファイルを作成または取得
2. `VRMA/`ディレクトリに配置
3. `index.html`の`VRMA_ANIMATIONS`配列に`{ name, url }`を追加するだけでボタンが自動生成されます（HTMLの変更は不要）

### スタイリング

インターフェースは簡単なテーマ設定のためにCSSカスタムプロパティを使用。主要な変数：

- 背景色とグラデーション
- ボタンスタイルとホバー効果
- コントロールパネルの外観
- レスポンシブブレークポイント
